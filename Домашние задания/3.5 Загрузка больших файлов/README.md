# Загрузка больших файлов

Домашнее задание к занятию 3.5 «Асинхронные запросы: отправка данных и отслеживание прогресса».

## Описание 

Необходимо разработать индикатор загрузки большого файла, отправленного через AJAX.

![Demo](./demo.gif)

### Исходные данные

1. Основная HTML-разметка

Для индикации прогресса пользуйтесь тегом *progress*, находящимся в разметке:

```html
<progress value="0.0" id="progress"></progress>
```

Для манипуляции тегом пользуйтесь его свойством *value*:

```js
const progress = document.getElementById( 'progress' );
progress.value = 0.7;
```

### Процесс реализации

1. Загрузите форму через AJAX по адресу *https://students.netoservices.ru/nestjs-backend/upload*
2. Отслеживайте событие изменения загрузки и в соответствии 
с ним корректируйте прогресс
3. **Важно** Если отправка формы будет реализована неверно, вы можете получить ошибку от сервера.

### Файлы в этой папке

| Файл | Назначение |
|------|------------|
| `task.html` | Разметка: форма с полем выбора файла, кнопка «Отправить», элемент `<progress>` |
| `task.css` | Стили карточки и кастомного отображения `input type="file"` |
| `main.js` | Подстановка имени выбранного файла в подпись (шаблон задания) |
| `task.js` | Отмена обычной отправки формы, `POST` через `XMLHttpRequest` с `FormData`, обновление `progress` в обработчике `xhr.upload` → `progress` |

## Подсказки (спойлеры)

<details>
<summary>Используемые темы</summary>

1. Событие *submit* формы и `preventDefault`
2. Объект `FormData` для передачи файла и полей формы
3. `XMLHttpRequest` и событие `upload.progress` (или `fetch` не даёт прогресс загрузки — для индикатора удобнее XHR)
4. Свойство `lengthComputable` и расчёт доли `loaded / total`

</details>

<details>
<summary>Советы</summary>

1. Не отправляйте форму обычным способом — перехватывайте *submit* и отправляйте данные скриптом.
2. Перед новой отправкой можно сбрасывать `progress.value` в `0`.
3. Убедитесь, что в `FormData` попадает файл из поля с атрибутом `name` (в шаблоне — `file`).

</details>
